# VFX Check

Upload a VFX or CG clip and get an AI critique: is it good enough to post?
Runs fully free using Google Gemini's free API tier.

## Publish on GitHub Pages
1. Create a new GitHub repository (public).
2. Upload `index.html` and `README.md`.
3. Settings → Pages → Source: **Deploy from a branch** → branch `main`, folder `/ (root)` → Save.
4. After about a minute your site is at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Free key
Each visitor gets a free key at https://aistudio.google.com/apikey (no credit card) and pastes it into the box on the page. It is saved only in their own browser. Never write a key into the code.

Free tier has daily limits. Only 10 small still frames are sent to the AI; the video itself never leaves the browser.
